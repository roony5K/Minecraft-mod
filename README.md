# Auto Trade (Minecraft 26.3 Fabric)

Select any trade in a villager's trading window, then click **Auto Trade: OFF** (or press **K**) to turn it **ON** and automatically repeat that trade until it runs out of stock or you close the screen.

## Build in your browser with GitHub Actions (no installs needed)
1. Unzip `autotrade-fabric-26.3.zip`.
2. Create a new empty repository on GitHub.
3. Upload all the files inside `autotrade-fabric-26.3/` (including the `.github` folder) and commit them.
4. Click the **Actions** tab on your GitHub repo, wait ~1-2 minutes for **Build Fabric Mod** to finish, and download **`autotrade-fabric-26.3`** from **Artifacts** at the bottom.
5. Unzip that download to get `autotrade-1.0.0.jar`, then add it to your 26.3 Fabric profile in the **Modrinth App** (**Add content -> From file**) alongside **Fabric API**.
